Created by Bratindra Reddy Thati on 6/12/26, deployed to GitHub on 8/13/26. 
FinSight is an AI-powered investment research agent that generates concise research reports on public companies using real-time financial data from Finnhub, recent news from GNews, and LLM-powered analysis through OpenRouter. 
Built with Python and Streamlit, FinSight provides company overviews, financial snapshots, recent developments, strengths, and risks through an interactive interface. 
This project is for educational purposes and does not provide financial advice.
